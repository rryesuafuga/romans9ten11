## Daily news brief

Every day at 03:07 Uganda time (00:07 UTC) a Claude Code routine searches world
news from the previous ~30 hours on Israel, Jews in Israel, Judea and Samaria
and Jewish diaspora communities. It writes `daily/YYYY-MM-DD.md`, records what
it covered in `seen.json`, refreshes the summary below, and commits to `main`.

- Setup and operations: [`SETUP.md`](SETUP.md)
- Format rules for a daily file: [`daily/README.md`](daily/README.md)
- The routine's instructions: [`routine/PROMPT.md`](routine/PROMPT.md)
- News sources it pulls: [`routine/sources.json`](routine/sources.json)
